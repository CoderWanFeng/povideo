## 第三方服务接入文档

本项目集成了腾讯云语音识别（ASR）服务，用于实现音频到文本的转换功能。相关接入文档如下：

- **腾讯云语音识别（ASR）API官方指南**：[https://cloud.tencent.com/document/product/1093](https://cloud.tencent.com/document/product/1093)
- **腾讯云SDK for Python文档**：[https://cloud.tencent.com/document/sdk/Python](https://cloud.tencent.com/document/sdk/Python)
- **本地语音识别接口说明**：[https://cloud.tencent.com/document/product/1093/35687](https://cloud.tencent.com/document/product/1093/35687)

在使用`audio2txt`功能时，需准备以下腾讯云凭证：
- `appid`：腾讯云项目ID
- `secret_id` 和 `secret_key`：API密钥对

## 核心配置参数速查表

以下为项目中关键功能的配置参数参考：

### 腾讯云ASR配置
| 参数 | 可选值 | 说明 |
|------|--------|------|
| engine_model_type | "8k_6", "16k_0", "16k_en" | 引擎模型类型：8k电话音频，16k中文普通话，16k英文 |
| channel_num | 1, 2 | 音频声道数 |
| res_text_format | 0, 1, 2 | 返回文本格式：0-无标点，1-有标点，2-自动加标点 |
| projectid | 0（默认项目） | 腾讯云项目ID |

### 音频与视频处理配置
| 参数 | 可选值 | 说明 |
|------|--------|------|
| 采样率 | 8000Hz, 16000Hz | 推荐使用16kHz采样率以获得更好的识别效果 |
| 音频格式 | WAV, MP3, AMR等 | 本地文件建议使用WAV格式，大小不超过5MB |
| 视频水印字体 | TrueType字体路径 | 如`C:\Windows\Fonts\arial.ttf`，支持中文字体需确保系统已安装 |
| 水印位置 | (x, y)坐标元组 | 水印在视频画面中的位置，原点为左上角 |

### pyttsx3语音合成配置
| 参数 | 可选值 | 说明 |
|------|--------|------|
| speak | True, False | 是否实时朗读生成的语音 |
| mp3 | 文件路径或None | 是否将语音保存为MP3文件，None表示不保存 |
