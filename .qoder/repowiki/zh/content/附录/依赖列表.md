## 项目依赖总览

根据项目配置文件 `setup.cfg` 中的 `install_requires` 字段，povideo 项目的外部依赖库包括：

- **moviepy**：用于视频剪辑处理与水印合成
- **tencentcloud-sdk-python**：调用腾讯云语音识别（ASR）服务
- **pyttsx3**：实现本地文字转语音功能
- **requests**：发起HTTP请求，支持腾讯云API通信
- **pathlib**：现代化路径操作工具，提升跨平台兼容性
- **pofile**：文件搜索与管理辅助工具

这些依赖均通过 `pip` 包管理器自动安装，无需手动编译或复杂配置。

## 核心依赖库详细说明

### moviepy（视频处理）
- **作用说明**：用于视频文件的读取、编辑、合成与导出，支持添加文字/图片水印、提取音频等操作。
- **官方文档链接**：[https://zulko.github.io/moviepy/](https://zulko.github.io/moviepy/)
- **版本要求**：无特定版本限制，兼容最新稳定版。

### pyttsx3（文字转语音）
- **作用说明**：本地TTS引擎，将文本内容转换为语音输出，支持离线朗读和保存为MP3文件。
- **官方文档链接**：[https://github.com/nateshmbhat/pyttsx3](https://github.com/nateshmbhat/pyttsx3)
- **版本要求**：无特定版本限制。

### tencentcloud-sdk-python（腾讯云ASR服务）
- **作用说明**：调用腾讯云语音识别API，将音频文件转换为文字内容，适用于录音转文字场景。
- **官方文档链接**：[https://github.com/TencentCloud/tencentcloud-sdk-python](https://github.com/TencentCloud/tencentcloud-sdk-python)
- **版本要求**：需安装 `tencentcloud-sdk-python` 最新版以确保API兼容性。

### requests（HTTP请求库）
- **作用说明**：发送HTTP POST请求至腾讯云ASR接口，实现语音识别任务提交与结果获取。
- **官方文档链接**：[https://docs.python-requests.org/](https://docs.python-requests.org/)
- **版本要求**：支持Python 3.7+环境下的任意稳定版本。

### pathlib（路径操作）
- **作用说明**：提供面向对象的路径操作接口，简化文件路径拼接、解析与跨平台兼容处理。
- **官方文档链接**：[https://docs.python.org/zh-cn/3/library/pathlib.html](https://docs.python.org/zh-cn/3/library/pathlib.html)
- **版本要求**：Python 3.7+ 内置模块，无需额外安装。

### pofile（文件管理工具）
- **作用说明**：辅助进行目录遍历与文件筛选，提升批量处理效率。
- **官方文档链接**：[https://pypi.org/project/pofile/](https://pypi.org/project/pofile/)
- **版本要求**：无特定版本限制。

## 安装方式与配置要求

所有依赖均通过 `pip` 自动安装，命令如下：

```bash
pip install -i https://mirrors.aliyun.com/pypi/simple/ povideo -U
```

## 常见安装问题与解决方案

### 1. Windows下pyttsx3无法运行
- **问题现象**：报错 `No module named 'win32com.client'` 或 `ImportError: Unable to load the engine`
- **原因**：pyttsx3依赖 `pywin32`，但不会自动安装
- **解决方案**：
  ```bash
  pip install pywin32
  ```
  安装后重启Python环境即可。

### 2. moviepy因缺少FFmpeg报错
- **问题现象**：执行视频处理时报错 `MoviePy error: FFMPEG executable not found`
- **原因**：moviepy依赖FFmpeg进行视频编码解码
- **解决方案**：
  - 方法一（推荐）：使用conda安装（自动包含FFmpeg）
    ```bash
    conda install -c conda-forge moviepy
    ```
  - 方法二：手动下载FFmpeg并配置环境变量
    1. 下载地址：[https://ffmpeg.org/download.html](https://ffmpeg.org/download.html)
    2. 解压后将 `bin` 目录添加到系统PATH
    3. 验证安装：`ffmpeg -version`

### 3. 腾讯云SDK认证失败
- **问题现象**：调用 `audio2txt` 报错 `Authentication failed`
- **原因**：SecretId或SecretKey错误，或网络无法访问腾讯云API
- **解决方案**：
  - 检查密钥是否正确
  - 确保网络通畅，可尝试访问 `https://asr.tencentcloudapi.com`
  - 使用代理时需配置HTTP代理

## 依赖在项目中的使用场景

### moviepy：视频水印合成
在 `mark2video` 功能中，使用 `moviepy` 实现视频加载、文字水印创建与合成输出：
```python
from moviepy.editor import VideoFileClip, TextClip, CompositeVideoClip
```
该功能位于 `dev/2、给视频加水印.py` 和 `povideo/api/video.py` 中。

### pyttsx3：文字转语音
在 `txt2mp3` 功能中，调用 `pyttsx3.speak()` 实现语音朗读，并使用 `engine.save_to_file()` 保存为MP3文件：
```python
import pyttsx3
pyttsx3.speak("程序员晚枫")
```
相关代码见 `dev/1、文字转语音.py` 和 `povideo/api/video.py`。

### tencentcloud-sdk-python：语音识别
在 `audio2txt` 功能中，通过腾讯云ASR客户端提交音频文件并轮询识别结果：
```python
from tencentcloud.asr.v20190614 import asr_client, models
```
核心实现位于 `povideo/lib/tencent/audio2txt_service.py`。

### requests：API通信
在腾讯云ASR请求中，使用 `requests.post()` 发送音频数据：
```python
r = requests.post(task_req_url, headers=header, data=body_data)
```
用于任务提交与状态查询。

### pathlib：路径处理
在 `txt2mp3` 和 `mark2video` 中统一使用 `Path(output_path) / output_name` 构建跨平台兼容路径：
```python
from pathlib import Path
```
提升代码可读性与健壮性。

### pofile：文件批量处理
在示例脚本中使用 `get_files()` 批量获取目录下所有视频文件：
```python
from pofile import get_files
v_fs = get_files(r'D:\BaiduNetdiskDownload\...')
```
简化文件遍历逻辑。
