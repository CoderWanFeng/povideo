# 视频水印工具 GUI 应用

基于 PySide6 开发的视频水印添加工具，提供科技感的用户界面和便捷的操作体验。

## 功能特性

### 核心功能
- ✨ **单文件处理**：为单个视频文件添加自定义文字水印
- 📦 **批量处理**：支持选择文件夹，自动处理所有视频文件（递归扫描子目录）
- 🎨 **样式定制**：支持自定义字体大小、颜色和字体文件
- ⚡ **异步处理**：视频处理在后台线程执行，界面保持响应
- 📊 **进度反馈**：实时显示处理状态和进度

### 界面特色
- 🌌 **科技感深色主题**：专业的暗色界面设计
- ✨ **渐变色和发光效果**：增强视觉吸引力
- 🎯 **操作位置清晰**：分组布局，每个功能模块独立
- 🔔 **即时反馈**：悬停、点击、聚焦等操作都有视觉反馈

### 支持的视频格式
- MP4、AVI、MOV、MKV、WMV
- FLV、M4V、MPEG、MPG

## 快速开始

### 前置要求

确保已安装以下依赖：
```bash
pip install PySide6
pip install povideo
```

### 运行应用

```bash
python mark2video_gui.py
```

### 使用步骤

#### 单文件模式

1. **选择视频文件**
   - 点击「📁 输入设置」区域的「📂 浏览」按钮
   - 在弹出对话框中选择「📄 单个视频文件」
   - 浏览并选择要处理的视频文件

2. **输入水印文字**
   - 在「水印文字」输入框中输入要添加的水印内容
   - 默认值：`www.python-office.com`

3. **设置输出路径**
   - 在「💾 输出设置」区域设置输出目录
   - 设置输出文件名（需以 .mp4 结尾）
   - 默认输出路径：`./`
   - 默认文件名：`mark2video.mp4`

4. **自定义字体样式**（可选）
   - **字体大小**：调整数字输入框（范围：8-200，默认：28）
   - **字体颜色**：点击「🎨 选择」按钮打开颜色选择器
   - **字体文件**：点击「📂 浏览」选择自定义字体文件（默认：arial.ttf）

5. **开始处理**
   - 点击「🚀 开始处理」按钮
   - 等待处理完成（进度条显示处理状态）
   - 处理完成后会弹出成功提示

#### 批量处理模式

1. **选择视频文件夹**
   - 点击「📁 输入设置」区域的「📂 浏览」按钮
   - 在弹出对话框中选择「📁 批量处理（文件夹）」
   - 浏览并选择包含视频文件的文件夹

2. **配置水印和样式**
   - 与单文件模式相同，配置水印文字和字体样式
   - 注意：批量模式下「文件名」输入框会被禁用并显示「[批量模式-自动命名]」

3. **设置输出路径**
   - 在「💾 输出设置」区域设置输出目录
   - 批量处理会保持原有的目录结构
   - 每个文件自动添加「-水印版」后缀

4. **开始批量处理**
   - 点击「🚀 开始处理」按钮
   - 系统会显示找到的视频文件数量，询问是否确认
   - 确认后开始批量处理
   - 处理完成后显示成功和失败的统计信息

## 常见问题

### Q: 支持哪些视频格式？
A: 支持常见的视频格式，包括 MP4、AVI、MOV、MKV、WMV、FLV、M4V、MPEG、MPG 等。

### Q: 批量处理时会保持原有目录结构吗？
A: 是的，批量处理会递归扫描所有子文件夹，并在输出目录中保持相同的目录结构。

### Q: 输出文件会覆盖原文件吗？
A: 不会。输出文件会保存到指定的输出目录，原文件不会被修改。单文件模式下可以自定义输出文件名，批量模式会自动添加"-水印版"后缀。

### Q: 处理过程中界面会卡住吗？
A: 不会。视频处理在后台线程执行，主界面保持响应。您可以看到实时的处理状态和进度条。

### Q: 字体文件在哪里找？
A: Windows 系统字体位于 `C:\Windows\Fonts\` 目录。常用字体如：
- 微软雅黑：`msyh.ttc`
- Arial：`arial.ttf`
- 黑体：`simhei.ttf`

### Q: 批量处理失败了怎么办？
A: 批量处理完成后会显示成功和失败的统计，以及失败文件的列表。您可以查看错误信息，修正问题后重新处理失败的文件。

如果需要打包成 Windows 可执行文件，可以使用 PyInstaller：


## 技术架构

- **GUI框架**：PySide6 (Qt6 for Python)
- **视频处理**：povideo 库（支持 FFmpeg 和 moviepy 双引擎）
- **异步处理**：QThread（防止 UI 阻塞）
- **样式系统**：QSS（类似 CSS 的样式定义）
